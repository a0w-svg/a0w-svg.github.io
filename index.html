AzamiOS — 64-Bit x86_64 Operating System

A 64-bit Long Mode operating system built from scratch featuring a Unix FHS hierarchy, unmodified Linux x86_64 ELF binary execution, a custom POSIX freestanding C library, hardware drivers, and the Azami Window Manager (azwm).

a0w-svg/AzamiOS Predecessor: JakOS (x86-32)

Kernel, Syscall ABI & Userspace Architecture

x86_64 Long Mode (PML4) Linux Syscall ABI (82-check probe) Limine UEFI / BIOS 40+ Custom POSIX libc Headers VirtIO + xHCI USB 3.x + e1000/RTL8169 azwm Compositor + X11 Protocol GPL-2.0 Kernel / BSD-3 Userspace

Preemptive x86_64 Kernel & Unmodified Linux Binaries

Implements the System V AMD64 Linux syscall ABI so static binaries compiled by an ordinary Linux toolchain execute directly without shims or source patches.

  • Memory & Paging: Physical Memory Manager (PMM), slab kmalloc, 4-level PML4 paging with mmap/munmap and POPCNT bitmap acceleration.
  • Scheduling & Signals: Preemptive per-CPU run queues, ELF64 loader, POSIX threads, job control (SIGSTOP/SIGTSTP/SIGCONT, wait4).
  • Debugging & PMU: Full ptrace(2) (TRACEME, ATTACH, SEIZE, int3, single-step, COW-safe PEEK/POKE) + perf_event_open(2) hardware PMU counters.
  • ~20 ns vDSO Timekeeping: KVM pvclock / VMware TSC clocksource with sub-tick one-shot TSC-deadline interrupts for 1 ms precision nanosleep.
  • CPU Security & Extensions: SMEP, SMAP, UMIP, PKU, NX, FSGSBASE, PCID, XSAVE/XSAVEC, RDRAND/RDSEED, SSE4.2 CRC-32C dentry hashing, and exception-fixup boot probing.

Hardware Abstraction Layer (HAL), Storage, USB 3.x & Network Stack

Modular PCI bus enumeration with MSI/INTx routing, I/O APIC + LAPIC SMP interrupts, and paravirtual + physical device drivers.

  • Networking Cards: Intel e1000 / e100, Realtek RTL8139 / RTL8169 (Gigabit), AMD PCNet, VMware VMXNET3, and VirtIO-Net.
  • TCP/IP Stack: Full Ethernet, ARP, IPv4, ICMPv4, UDP, TCP, BSD sockets, dhcpcd, ntpd, httpd, curl, and nslookup.
  • USB & Input: xHCI (USB 3.x) with BIOS handoff, Intel PCH port routing, hot-plug, USB HID keyboards/mice/tablets, PS/2, and virtio-input.
  • Audio & Video: Intel HDA, AC'97, ES1370, MPU-401 MIDI, PC Speaker; VirtIO GPU, BGA Display, and Framebuffer DRM.
  • Storage: ATA IDE, Floppy DMA/FDC, VirtIO Block, and VirtIO 9P host filesystem sharing.

Freestanding POSIX C Library (userland/libc/) & Ported Packages

Zero kernel leakage into userspace, licensed under BSD-3-Clause alongside a rich software ports tree installable via pkg.

  • Core POSIX & Linux APIs: stdio.h, stdlib.h, pthread.h, sys/epoll.h, linux/futex.h (including futex2), sys/statx.h, sys/sendfile.h, spawn.h, mqueue.h, regex.h, ftw.h.
  • System Shell & Toolchain: GNU Bash 5.2 as /bin/sh (plus native azami-sh), TinyCC (tcc) & GNU Make on-device compiler toolchain.
  • Ported Ecosystem: musl 1.2.5 + BusyBox 1.36.1 (401 applets), Lua, MicroPython, SQLite, jq, gawk, curl, nano, less, tree.

Azami Window Manager (azwm), X11 Support & Virtual Filesystem

Complete desktop environment over a double-buffered alpha-blending software compositor and Unix FHS root tree.

  • Desktop Apps: azwm window manager, terminal, texteditor, filemanager, sysmon, calculator, paint, and games (minesweeper, 2048, snake).
  • X11 Client Protocol: Runs classic X11 clients including xclock, xcalc, xeyes, and xcursor.
  • VFS & Filesystems: ext2, FAT32, ProcFS, SysFS, DevFS, Devpts, PipeFS, and TarFS initrd with POSIX ACLs (getfacl/setfacl).
